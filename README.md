# Aldeia II — plano elétrico (térreo): pontos para ajustar

Página para celular (use na horizontal). Abra `index.html` ou ative o GitHub Pages (Settings → Pages → Deploy from branch → main → / (root)).

## Como usar
- A fileira de números no topo (1–18) leva a cada ponto da planta. Toque num número ou num círculo: a planta dá zoom no local e a foto aparece à direita, com a observação embaixo.
- **Âmbar** = ajustar posição de ponto existente. **Verde** = ponto novo.
- O botão **Palco** mostra a foto do palco com os eletrodutos de som e energia.
- **＋** adiciona um ponto novo.
- **◐** (canto inferior esquerdo da planta) abre um controle deslizante que mistura o desenho elétrico original com o contorno das paredes.
- **Enviar por WhatsApp** manda a observação (já escrita) para o número configurado.

## Arquivos
- `index.html` — página principal
- `walls.png` — contorno das paredes · `elec.jpg` — planta elétrica original
- `thumbs/` — fotos dos pontos 1–14 · `palco/` — vista do palco (e PDF)
