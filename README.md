# Aldeia II — electrical plan adjustments (ground floor)

Interactive page: the electrical plan (`plan.jpg`) with numbered points taken from site photos (`thumbs/`).

- Drag each numbered circle to its place on the plan.
- Amber = existing point to adjust. Green + = new point.
- Tap a point to see its photo, write an observation, and send it by WhatsApp.
- "Copiar posições" copies all positions and notes as text.

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → main) to get a public link.
